# Student Portal 🎓

A clean, simple, and semantic **Student Portal** webpage built using HTML5 and foundational CSS.

## 🚀 Overview

This project was built as part of an HTML & CSS lab assignment to demonstrate core web development fundamentals:
- **Semantic HTML**: `<header>`, `<nav>`, `<main>`, `<section>`, and `<footer>`
- **Data Representation**: Structured tables for student profile information and a weekly timetable schedule
- **Forms & Inputs**: Complete registration form with text, email, select dropdowns, grouped radio buttons, checkboxes, and form buttons with proper `<label>` elements
- **CSS Fundamentals**: Element selectors, Class selector (`.highlight`), and ID selector (`#student-name`)
- **No Complex Layouts**: Built without JavaScript, CSS frameworks, Flexbox, or Grid for pure foundational clarity

## 📁 Files

- `student-portal.html`: Primary assignment HTML file with embedded styling
- `index.html`: Webpage entrypoint for easy browser viewing

## 💻 How to View

1. Clone or download the repository:
   ```bash
   git clone https://github.com/tanayAgarwaL524/student-portal.git
   ```
2. Double-click `student-portal.html` or `index.html` to open it in any modern web browser.
